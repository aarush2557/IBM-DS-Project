
# 🪔 Diwali Sales Analysis

## Project Overview
This project analyzes Diwali sales data using Python
and Data Science techniques to understand customer
purchasing behavior and sales trends.

## Technologies Used
- Python
- Jupyter Notebook
- Anaconda
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## Project Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Gender-wise Sales Analysis
- Age Group Analysis
- State-wise Sales Analysis
- Occupation Analysis
- Product Category Analysis
- Interactive Streamlit Dashboard

## Project Structure
- Dataset.ipynb - Data analysis notebook
- app.py - Streamlit dashboard
- Dataset.csv - Dataset (if redistribution is permitted)
- requirements.txt - Python dependencies

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py
